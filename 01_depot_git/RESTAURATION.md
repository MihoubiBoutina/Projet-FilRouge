# Instructions de restauration du dépôt Git (01_depot_git)

Ce dossier contient l'historique complet du projet MyProf sous forme de bundle Git.

## Commande de restauration

Pour cloner et restaurer le dépôt complet (avec branches et tags) :

```bash
git clone depot.bundle MyProf-Restaure
cd MyProf-Restaure
git checkout main
```
